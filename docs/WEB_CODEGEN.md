# Web Codegen (contract-driven)

The web API layer is **generated from server contracts** — a single typed source
of truth. No regex parsing, no hand-duplicated method/DTO declarations.

## How it works

1. Each server module declares its HTTP surface once via `defineContract(...)`
   in its `*.contract.ts`, referencing the real Zod DTOs:

   ```ts
   // apps/server/src/modules/location/location.contract.ts
   import { defineContract, dto, endpoint, shared } from '@/shared/contract/define-contract'

   export const locationContract = defineContract({
     feature: 'location',            // web feature namespace + folder
     prefix: '/location',            // Elysia route prefix
     dtoSource: 'location/location.contract.ts',
     endpoints: [
       endpoint({
         action: 'list',
         method: 'get',
         path: '/list',
         input: { kind: 'query', ref: dto(LocationFilterDto, 'LocationFilterDto') },
         output: { kind: 'paginated', ref: dto(LocationDto, 'LocationDto') },
       }),
       // ...
     ],
   })
   ```

   - `dto(schema, 'Name')` — DTO exported from this contract file (copied to web).
   - `shared(schema, 'zc.RecordId')` — shared validation primitive (`zc`/`zp`/`zq`).
   - `output.kind`: `single` → `createSuccessResponseSchema`, `paginated` →
     `createPaginatedResponseSchema`.
   - `input.kind`: `query` → api-factory `params`, `body` → api-factory `body`.

2. Register the contract in `scripts/generate-web.ts` (`loadContracts()`).

3. Run the generator:

   ```sh
   bun run generate:web            # all registered contracts
   bun run generate:web location   # one feature
   bun run generate:web:preview    # dry-run, prints target paths
   ```

## Generated output (per feature)

```
apps/web/src/features/<feature>/dto/<name>.dto.ts   # copied DTOs, import → @/lib/validation
apps/web/src/features/<feature>/dto/index.ts        # barrel
apps/web/src/features/<feature>/api/<name>.api.ts   # typed apiFactory calls
apps/web/src/features/<feature>/api/index.ts        # barrel
apps/web/src/config/endpoint.gen.ts                 # URL map for all features
```

All generated files start with `// AUTO-GENERATED by scripts/generate-web.ts — DO NOT EDIT.`

## Rules

- **Never hand-edit generated files.** Change the server contract and re-run.
- The DTO copy strips the `defineContract` import + the `export const …Contract`
  block and rewrites `@/shared/schema` → `@/lib/validation`. Keep DTOs free of
  server-only imports so they copy cleanly.
- Validation helpers on web live in `@/lib/validation` (the `@ikki/api-contract`
  alias is deprecated; migrate remaining features to `@/lib/validation`).
- Web keeps `ky` + `apiFactory` + TanStack Query. `.query(params)` →
  `queryOptions`; `.mutationFn` → `useMutation`.
